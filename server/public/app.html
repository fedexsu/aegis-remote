Your links

Each link has two versions — both enroll the machine to your account: .exe = the installer (they double-click it, installs silently) · .vbs = one-click silent installer (no window at all). Use Copy .exe link / Copy .vbs link to share, or Download to grab the file yourself. The key is baked into the download filename, so a device enrolls automatically. (A raw installer with no key won't appear here.)

How do I set this up?
  1. In Telegram, message @BotFather → /newbot → copy the bot token and paste it above.
  2. Open your new bot in Telegram and tap Start (or send it any message). This step is required — a bot can't message you until you do.
  3. Click Find my Chat ID above — it fills in your Chat ID automatically.
  4. Hit Send test to confirm, then Save.
